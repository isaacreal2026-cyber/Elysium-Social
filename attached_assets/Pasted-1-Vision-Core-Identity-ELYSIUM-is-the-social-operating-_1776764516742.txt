1. Vision & Core Identity
ELYSIUM is the social operating system for the next decade.
It fuses the virality of TikTok, the intimacy of close friends, the depth of Discord, the discovery of dating apps, and the utility of LinkedIn into one elegant, living ecosystem.

Core Promise: Every interaction creates resonance.

Signature Differentiators (Anti-Cloning Protection):

Orbital Navigation System — No traditional bottom tab bar. Central glowing orb with context-aware floating orbs.
Resonance Engine — Proprietary AI that actively cultivates meaningful engagement.
Fractal Content System — Any post can contain fully functional nested posts/worlds.
Spatial Hubs — Groups feel like 2.5D living rooms with depth, layers, and orbiting elements.
Soulprint Profiles — Rich, evolving digital identities.
Tagline: "Where every connection resonates."

4. UI/UX Design System (Signature Style)
Philosophy: Beautiful, alive, emotional, calm, premium.

Color System: Deep cosmic gradients (deep purples, teals, golds) with reactive glows based on user energy.
Typography: "Satoshi" or "Neue Montreal" with variable weight.
Motion: All interactions use spring physics (Flutter's SpringSimulation). Heavy use of particle systems on resonance actions.
Depth System: Every screen has 4 layers of parallax depth.
Signature Elements:
Glowing central orb with breathing animation
Resonance actions create visible energy ripples that can propagate to friends
Content cards have "living borders" that react to interaction volume
Navigation Rule: Everything must feel one or two gestures away.

5. Resonance Engine (Core AI Brain)
Function:

Analyzes content tone, user emotional history, interest graph, and current energy level.
Suggests optimal interaction timing and type.
Creates "Spark Moments" — notifies small groups of people simultaneously to join the same post for collective resonance.
Powers intelligent feed ranking and notification timing.
Privacy-First Implementation:

On-device small models for personal data
Cloud models only on anonymized aggregated data
User can see "Why am I seeing this?" with full transparency
6. Database Schema Outline (High Level)
Key Collections:

Users (Soulprint data, personality weave, network graph)
Posts (fractal — parent_post_id, depth_level, content_container)
Resonance_Actions (user_id, post_id, type, energy_value)
Nexus_Hubs (spatial metadata, member_avatars positions)
Messages (standard + voice + project_mode)
Gather_Content (courses with progress paths)
Use hybrid: Firestore for real-time + PostgreSQL for complex queries + Neo4j for social graph.

8. Technical Stack
Frontend: Flutter 3.24+ (single codebase)
State Management: Riverpod + Signals
Animations: Rive + Custom shaders (impeller)
Backend: Firebase (auth, storage, basic realtime) + Supabase/PostgreSQL + Custom Go services for Resonance Engine
AI: TensorFlow Lite (on-device) + Grok/Claude API layer (cloud)
Real-time Voice: WebRTC + Agora fallback
Analytics: Mixpanel + custom privacy-first tracking
